# Installation

## Voraussetzungen

Benötigt werden:
- Python 3
- FFmpeg
- FFprobe

## Installation

Repository klonen:
```bash
git clone <DEINE-REPOSITORY-URL>
cd TUMDownloader
```

Danach das Installationsskript ausführen.
```bash
install.py
```


## Starten

Unter Windows:

```powershell
.venv\Scripts\python.exe main.py
```

Unter Linux/macOS:

```bash
.venv/bin/python main.py
```
